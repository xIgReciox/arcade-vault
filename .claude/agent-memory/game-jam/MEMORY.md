# Memoria de game-jam

Índice de lo que recuerda el agente. El historial de temas y juegos está en `jams.md`.

## Preferencias del equipo

- Un tema → un juego → tres specs encadenados (`01` juego, `02` pulido, `03` contenido) en `specs/game-jam/<id>/`.
- Autónomo: sin preguntas a mitad de trabajo; las decisiones se registran en cada spec como «Decisión autónoma de game jam».
- Los specs quedan en `Borrador`; los aprueba el humano.
- Sin assets de referencia: sprites SVG escritos a mano + sonido sintetizado con Web Audio (patrón usado en sapo-voltio-02).
- Nunca usar nombres comerciales como id/título (p. ej. `frogger` → `sapo-voltio`).

## Archivos

- [jams.md](jams.md) — historial de temas, ids, categoría, color y estado.
