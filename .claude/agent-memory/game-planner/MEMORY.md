# Memoria de game-planner

- [Historial de sugerencias](suggestions.md) — tabla de juegos propuestos, aceptados, implementados y descartados.

## Preferencias del equipo

- UI y copy en español.
- Juegos de un jugador con teclado, canvas 800×600, sin multijugador online.
- Juegos originales: mecánica de género con nombre y estética propios, sin clonar marcas.
- Flujo: `game-planner` decide → `/add-game` escribe el spec → `/spec-impl` implementa.
